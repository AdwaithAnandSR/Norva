title: String for the title of the screen shown in the tab bar.
 * tabBarLabel: String or function that returns a React element to display as the label for the tab.
 * tabBarIcon: Function that returns a React element to display as the icon for the tab. It receives an object with focused (boolean) and color as arguments.
 * tabBarActiveTintColor: Color for the active tab icon and label.
 * tabBarInactiveTintColor: Color for the inactive tab icon and label.
 * tabBarActiveBackgroundColor: Background color for the active tab.
 * tabBarInactiveBackgroundColor: Background color for the inactive tab.
 * tabBarShowLabel: Boolean to show or hide the label.
 * tabBarHideOnKeyboard: Boolean to hide the tab bar when the keyboard is open.
 * tabBarStyle: Style object for the tab bar container.
 * tabBarLabelStyle: Style object for the tab label.
 * tabBarItemStyle: Style object for the individual tab item.
 * tabBarButton: Function that returns a React element to render a custom tab button.
 * tabBarBadge: String or number to display a badge on the tab.
 * tabBarBadgeStyle: Style object for the badge.
 * tabBarAccessibilityLabel: Accessibility label for the tab button.
 * tabBarTestID: Test ID for the tab button.
 * headerShown: Boolean to show or hide the header for the screen.
 * headerTitle: String or function that returns a React element to display as the header title.
 * headerStyle: Style object for the header.
 * headerTintColor: Tint color for the header.
 * headerTitleStyle: Style object for the header title.
 * headerRight: Function that returns a React element to display on the right side of the header.
 * headerLeft: Function that returns a React element to display on the left side of the header.
 * href: (Specific to Expo Router) Allows you to control the route associated with the tab. Setting href: null can hide a tab from the tab bar.
Props for Custom Tab Layouts using expo-router/ui:
When using the unstyled components from expo-router/ui (which are more for building highly custom tab bars), the Tabs component acts as a wrapper. The actual navigation logic is handled by TabTrigger components within a TabList.
 * Tabs: This is primarily a wrapper component. It doesn't have many direct props for styling or behavior beyond what a standard View would have, as its purpose is to contain the TabList and TabSlot.
 * TabTrigger: This is where you define the route for each tab.
   * href: The route path for the tab (required when used within TabList).
   * name: A unique name for the tab (required when used within TabList). This name can be used to reference the tab when switching.
   * reset: (From React Navigation) Controls when a tab resets its navigation state.
   * Other standard Pressable props, as TabTrigger renders as a Pressable.
 * TabList: A containing View for the list of TabTrigger components.
 * TabSlot: A slot to render the currently selected tab.
